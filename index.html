CPA 小白无脚本接入 NewAPI 教程

不运行脚本，不改系统设置。全程只做：下载、解压、复制配置、手动改几行、双击启动。

CPA 使用教程、AI 交流分享可以加 Q 群：753488355
本教程不要求运行任何脚本。你只需要按步骤下载 CPA，复制一个配置文件，手动改几行内容，然后双击启动程序。

一、你需要准备什么

需要准备 说明
CPA 压缩包 下载 CLIProxyAPI_xxx_windows_amd64.zip。普通 Windows 电脑选 amd64。
安装目录 建议固定放到 D:\CLIProxyAPI。
代理软件 例如 Clash / Mihomo。常见 HTTP 代理端口是 7890。
认证 JSON 后面在 CPA 后台上传，用来让 CPA 识别你的 Codex / OpenAI 认证。

二、最简单流程：照着 7 步走

1

下载 CPA

打开 GitHub Release 页面：

https://github.com/router-for-me/CLIProxyAPI/releases

普通 Windows 电脑下载这个类型：

CLIProxyAPI_xxx_windows_amd64.zip

不要下载 windows_aarch64，那个是 ARM 电脑用的。

2

解压到固定目录

把压缩包里面的文件放到：

D:\CLIProxyAPI

这个目录里至少应该有：

cli-proxy-api.exe
config.example.yaml
3

复制配置文件

在 D:\CLIProxyAPI 里找到：

config.example.yaml

复制一份，然后重命名为：

config.yaml
注意：一定是复制完整的 config.example.yaml，不要自己新建一个只有几行的 config.yaml。
4

打开 config.yaml，改 4 个地方

用记事本打开 D:\CLIProxyAPI\config.yaml。

第 1 个地方：确认端口

port: 8317

第 2 个地方：设置后台登录密码

找到：

remote-management:
  secret-key: ""

改成：

remote-management:
  secret-key: "admin123"

第 3 个地方：设置 NewAPI 调用密码

找到：

api-keys:
  - "your-api-key-1"
  - "your-api-key-2"
  - "your-api-key-3"

改成：

api-keys:
  - "sk-cpa-test-123"

第 4 个地方：设置代理

找到：

proxy-url: ""

如果你的代理端口是 7890，就改成：

proxy-url: "http://127.0.0.1:7890"
不知道代理端口就先试 7890。Clash / Mihomo 很多默认都是这个端口。
5

双击启动 CPA

双击：

D:\CLIProxyAPI\cli-proxy-api.exe

黑窗口里看到下面这句，就说明启动成功：

API server started successfully on :8317

如果看到 :0，说明配置文件没复制完整，回到第 3 步重新复制。

6

打开 CPA 后台并上传 JSON

浏览器打开：

http://localhost:8317/management.html

用你刚才设置的后台密码登录，例如：

admin123

进入后台后，找到“认证文件管理”，上传你的 Codex / OpenAI JSON。

然后去“配额管理”里刷新配额。

7

NewAPI 添加 OpenAI 渠道

NewAPI 配置项 填写内容
渠道类型 OpenAI
Base URL http://127.0.0.1:8317/v1
API Key 填你在 api-keys 里设置的值，例如 sk-cpa-test-123

三、如果出问题，先看这里

你看到的问题 怎么处理
后台打不开 确认黑窗口里有没有 :8317。如果是 :0，重新复制完整的 config.example.yaml 为 config.yaml。
刷不出配额 / 出现 EOF 代理没通。先把代理软件切成全局模式，再换一个支持 OpenAI 的节点。
NewAPI 测试失败 确认 Base URL 是 http://127.0.0.1:8317/v1，API Key 是 api-keys 里设置的那个。
不知道代理端口 Clash / Mihomo 常见是 7890。如果不对，就去代理软件设置里找 HTTP 代理端口。
记住一句话：NewAPI 不用额外挂梯子。真正访问 OpenAI / Codex 的是 CPA，所以只要 CPA 的代理配置正确即可。
